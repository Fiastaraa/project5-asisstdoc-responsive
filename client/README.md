# AssistDoc Client

React + TypeScript + Vite + Tailwind CSS + Axios + React Router + Lucide.

## Install
```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

`VITE_API_URL=http://localhost:3000/api`

## Build
```powershell
npm run build
```

The client contains role-based routes for Admin, Doctor, Nurse, Pharmacist, and Patient.
